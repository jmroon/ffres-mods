# ffres-mods

Mods for FINAL FANTASY RESONANCE.

**[Anti-Aliasing Options](mods/anti-aliasing/README.md)** has two variants:
choose Off / FXAA / TAA / TSR in the graphics menu, or keep TSR always on.
Both preserve other graphics settings and can be packaged with or without UE4SS.

[Installation](mods/anti-aliasing/INSTALL.txt) ·
[Source](mods/anti-aliasing/src) ·
[Building](mods/anti-aliasing/BUILD.md)

**[Cinzel + Lato](mods/cinzel-lato/README.md)** gives headings a classic serif
and uses Lato for menus, dialogue and numbers. No UE4SS required.

[Installation](mods/cinzel-lato/INSTALL.txt) ·
[Building](mods/cinzel-lato/BUILD.md)
