# Cinzel + Lato

Cinzel Semibold headings with Lato menus, dialogue and numbers for
FINAL FANTASY RESONANCE. No UE4SS required.

[Download 1.0.0](https://github.com/jmroon/ffres-mods/releases/tag/cinzel-lato-v1.0.0)

**Install:** close the game, remove other font mods, and extract the release ZIP
beside `FFRS.exe`. Compatible with Anti-Aliasing Options.

**Remove:** delete the three `zz_CinzelSemiboldLato_P` files from
`FFRS/Content/Paks/~mods`. When switching from our earlier tests, remove that
variant's three files first.

Graphics settings and saves are untouched. Button artwork and image-based
battle logos retain their original lettering. Cinzel has no italic face;
chapter/title italic slots use upright Semibold. Lato italic text is preserved.

Tested by the maintainer on Steam build 24250053. Other languages and every UI
screen have not been exhaustively tested; see [build notes](BUILD.md).
