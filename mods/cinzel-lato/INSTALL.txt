Cinzel + Lato 1.0.1-battle15-test

Cinzel Semibold headings; Lato menus, dialogue, narration, character names and numbers.
Battle-panel test: names, HP/MP labels and numbers at size 15; lighter text shadows.
No UE4SS or runtime script required. Compatible with Anti-Aliasing Options.

Install
Close the game and remove other font mods, including any previous font-test
variant. Extract this ZIP into the game folder beside FFRS.exe.

Remove
Close the game and delete only these files from FFRS/Content/Paks/~mods:
  zz_CinzelSemiboldLato_P.pak
  zz_CinzelSemiboldLato_P.ucas
  zz_CinzelSemiboldLato_P.utoc

Graphics settings, saves and original game files are untouched.
Button artwork and image-based battle logos retain their original lettering.
Cinzel has no italic face; chapter/title italic slots use upright Semibold.
Lato's regular, bold and italic faces are preserved.

Tested by the maintainer on Steam build 24250053. Other languages and every UI
screen have not been exhaustively tested. Other font mods may conflict.
