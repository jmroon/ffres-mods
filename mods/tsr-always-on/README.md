# TSR Always On

Automatically enables TSR and keeps it active through loads and cutscenes.
No menu changes. Only the AA method is controlled; other graphics settings
stay as they are. TSR costs more GPU time than FXAA.

Extract the **Standalone** ZIP beside `FFRS.exe`, then launch normally.
Already have UE4SS? Use **Script-only** to preserve your loader configuration.
Use this mod or Anti-Aliasing Options, not both.
