# Repository guidance

For Steam game updates or mod compatibility investigations, use
[$ffres-compatibility](.agents/skills/ffres-compatibility/SKILL.md).
It covers automated checks, guided in-game testing, and the private update monitor.

Build commands, tool requirements, diagnostics, and monitor access are in
[BUILD.md](mods/anti-aliasing/BUILD.md).
Keep user-facing docs concise and preserve pending/unverified testing notes
until new evidence resolves them.
